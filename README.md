# la-theme

Lucky Apps 的独立主题插件。内置多套配色，跟随宿主的亮色 / 暗色模式，在设置中心「主题」或托盘右键菜单里切换。

## 内置主题

| 主题 | 说明 |
| --- | --- |
| 晨雾蓝 | 宿主默认的 JetBrains 蓝 |
| 樱花粉 | 柔和粉调 |
| 森野绿 | 低饱和绿 |
| 琥珀暖阳 | 暖棕底色 |
| 暮紫 | 冷静的紫调 |
| 午夜青 | 冷色深空 |
| 霓虹赛博 | 电光紫配冷蓝 |
| 薄荷汽水 | 带气泡感的青绿 |
| 蜜桃日落 | 珊瑚橘的傍晚 |

每套主题都有亮色和暗色两份调色板，切换明暗模式时自动换用对应配色。

## 托盘切换

托盘右键菜单的「主题」悬浮后在左侧展开二级菜单：3×3 缩略图网格（底色 / 侧栏 / 标题 / 面板 / 主色，标签在图下方，和设置中心的主题卡一致），当前主题带 ✓；点缩略图立即切换且不关菜单，方便连续比较，和设置中心共用同一份选择。

## 全局背景图

设置中心「主题」页点「设置背景图…」打开独立面板（宿主统一的 `AppDialog`），布局对齐 IDEA 的 Set Background Image：

- 左侧是 16:10 的预览区，按当前不透明度和布局实时渲染，右上角显示当前参数；
- 右侧是图片选择、不透明度滑杆（0–100%，默认 45%）与布局下拉；
- 布局：填充 / 适应 / 拉伸 / 居中 / 平铺；
- 支持 PNG / JPG / WebP / SVG，最大 20MB；预览区可以直接拖入图片；
- 图片存在 IndexedDB，选项存在 localStorage，重启后自动恢复；
- 图片在所有主题之后透出，亮色 / 暗色都会自动换成对应的半透明底色。

## 界面布局

宿主没有提供的界面能力，由插件在外围补齐：

- **图标拖动排序**：直接拖动左侧图标栏里的功能图标调整顺序，点击行为不变；键盘可用 `Alt + ↑/↓`。
- **面板拖宽**：拖动插件侧栏面板（如周报列表）右边缘调整宽度，双击手柄恢复默认；设置面板里也有滑杆。
- **图标尺寸 / 间距**：28–42px 图标、2–10px 间距实时调整。
- 全部按本机保存；新装的插件图标自动排在已排好的图标后面；停用插件后恢复宿主默认。
- 拖拽用 Pointer Events 实现（Tauri 的 WebView 会吞掉 HTML5 DnD），只改 CSS `order` / `width`，不搬 DOM，避免和宿主的 Vue 渲染打架。
- 主题卡片入场、选中、拖拽替身和换色光晕用 anime.js；`prefers-reduced-motion` 下自动关闭。

## 安装

在 Lucky Apps 仓库里执行（推荐装到用户 profile）：

```bash
pnpm lucky-apps plugin add ../la-theme --user
```

也可以在设置中心「扩展」的安装框里填本地目录路径。

## 开发

```bash
pnpm install
pnpm build
```

产物：

- `lib/client.js`：Cordis client bundle（CSS 已内联注入）
- `lib/node.js`：Node half，只负责把 client bundle 登记给宿主

## 实现方式

- `src/themes.ts`：主题数据 + 调色板到宿主颜色令牌的展开；
- `src/engine.ts`：把选中的主题写成 `html` 上的内联 CSS 变量，`localStorage` 记住选择；
- `src/background.ts`：背景图图层、IndexedDB 存取与布局 / 不透明度；
- `src/rail.ts`：侧边栏图标拖拽排序，Pointer Events + CSS `order` + localStorage，不改宿主代码；
- `src/tray.ts`：托盘右键「主题」一级项 + 左侧 3×3 缩略图二级菜单，`ctx.tray.registerItem` 的 `children` + `keepOpen` 注册，`addStyle` 排网格，换色后重新注册；
- `src/layout.ts`：面板拖宽、图标尺寸 / 间距，CSS 变量与 inline width；
- `animejs`：主题卡片入场、选中弹跳、拖拽替身与换色光晕；
- 选「晨雾蓝」且没有背景图时不写任何变量，直接使用宿主默认配色；
- 背景图模式下，`--wr-*` / `--el-*` 里的大面积底色换成半透明，图片从 `.la-theme-background` 图层透出；
- 主题页自带标题，加载时隐藏宿主给外部设置面板的通用占位标题，避免双标题和错误描述；
- 背景图设置弹窗使用宿主统一的 `@lucky-apps/client-ui` 的 `AppDialog`；
- 插件被停用 / 卸载时清掉图层、内联变量和排序样式，界面立即回到宿主默认状态；
- 主题只覆盖颜色令牌，不改布局、字体、圆角和阴影；布局增强由独立模块按需注入。

新增一套主题只需要在 `src/themes.ts` 的 `THEMES` 里追加一项，提供 `light` / `dark` 两份调色板。
